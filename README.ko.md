# 2D MV Lab

고정된 캐릭터 설정화와 검수한 전신 포즈 그림으로 짧은 2D 댄스 영상을 만드는 실험용 도구입니다. 대상 저장소는 `figurecurator/2d-mv-lab`이며, 현재는 게시 전 소스 준비본입니다.

캐릭터 원화 생성과 포즈 선택은 사람/에이전트가 별도로 수행합니다. 이 패키지는 투명 포즈 시트 분리, 명시적 앵커에 따른 배치, 타임라인, 선택적 RIFE 보간, 합성과 검증을 담당합니다. 설정화 한 장만 넣으면 완성되는 자동 영상 생성기는 아닙니다.

## 이번 벨리무맙 시험

《이계약국 영업일지》의 승인 시트 v1을 사용했습니다. 원본 안무의 1.2–4.2초에서 12개의 전신 원화를 생성하고, 반복 포즈를 재사용해 18개의 타임라인 키를 구성했습니다. 최종 출력은 720×1280, 60fps, 3초, 180프레임입니다.

이번 시험은 모든 그림에 같은 1.7배 전신 배율을 적용했습니다. 얼굴만 따로 확대·축소하거나 비틀어서 맞춘 것은 아닙니다. 얼굴 보호 영역의 변형을 줄이고, 몸의 다른 부분은 국소 흐름을 이용해 연결했습니다. 포즈 교체 순간의 튐과 머리카락·가운 형태 차이는 남아 있습니다.

실제 수행 단계, 수동 작업, 재현 범위는 [벨리무맙 제작 기록](docs/belimumab-pilot.md)에 구분해 두었습니다.

## 공개 구성

- `src/pose_mv`: 시트 분리·배치, 타임라인, RIFE 어댑터, 렌더와 검수 CLI.
- `tests`: 정지 시간 보존, 얼굴 변형 제한, 국소 제한, 분리 부품 보존, 잘림·덮어쓰기 방지 검사.
- `examples`: 외부 캐릭터·음원 없이 설치를 확인하는 도형 예제.
- `docs`: 설정 형식, 품질 검수, 공개 범위, 제작 사례와 게시 계획.

원래 작성한 코드·문서는 MIT 라이선스로 준비했습니다. 원본 춤 영상·음원, 캐릭터 시트, 생성 원화, 모델 가중치와 외부 구현은 공개 소스에 포함하지 않습니다.

설치 및 실행은 [영문 README](README.md), 게시할 내용과 상태는 [게시 계획](docs/publish-plan.md)을 참고하세요.
