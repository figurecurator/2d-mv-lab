# 벨리무맙 3초 시험: 실제 수행한 과정

이 문서는 완료한 시험의 기록입니다. 일반적인 개선 권장 사항과 실제 수행한 작업을 혼동하지 않도록 수치를 명시합니다. 캐릭터 자료와 원본 영상은 소스 저장소에 포함하지 않습니다.

## 1. 외형 기준 확인

사용자가 지정한 《이계약국 영업일지》의 Space 캐릭터 승인본에서 벨리무맙 시트 v1을 확인했습니다. 로컬 사본의 SHA-256이 Space 원본과 일치하는지 확인한 뒤 입력으로 사용했습니다. Ren’Py의 별도 화풍 시안은 사용하지 않았습니다.

고정 요소는 얼굴 인상, 호박색 눈, 긴 보라색 곱슬머리, 뿔·귀·귀걸이, 펜던트, 나비 브로치, 가운·셔츠·바지·신발입니다. 별도 얼굴 크롭을 생성 도구에 입력한 것은 아니며, 승인 시트 안의 얼굴 자료를 사용했습니다.

## 2. 안무 구간과 포즈 가이드

기존 원본 안무 영상은 30fps입니다. 프레임 36부터 126 직전까지, 즉 1.2–4.2초의 3초 구간을 사용했습니다.

원본의 팔 교차, 다리 뻗기, 무릎 굽힘, 손 제스처를 확인하고 생성할 포즈를 선택했습니다. 원본 프레임을 잘라 2열×3행 가이드로 만들었습니다. 이는 생성 모델에 자세를 전달하는 이미지이지, 관절 추적 결과가 아닙니다.

이번 배치 준비 스크립트는 단색 배경 차이로 인물 영역을, 원본 캐릭터의 붉은 머리색으로 머리의 가로 위치를 추정했습니다. 이 부분은 원본에 특화된 로컬 준비 작업이며, 공개 패키지의 범용 인체 검출 기능이 아닙니다. 다른 원본에서는 앵커를 다시 정해야 합니다.

## 3. 전신 원화 생성과 재사용

내장 ImageGen으로 6개 포즈가 든 투명 시트 2장을 생성했습니다. 첫 입력은 승인 캐릭터 시트와 첫 포즈 가이드입니다. 두 번째 생성에는 같은 승인 시트, 두 번째 포즈 가이드, 첫 생성 시트를 함께 넣어 묘사를 이어가도록 했습니다.

총 12개의 전신 원화이며, 개별 팔·다리 부품을 조립한 것이 아닙니다. 반복되는 뒤쪽 제스처는 6장을 다시 생성하는 대신 이미 만든 전신 그림을 재사용했습니다. 따라서 타임라인 키는 18개이지만 고유 생성 원화는 12개입니다. 재사용 때문에 원본의 작은 표정·자세 차이가 모두 재현되는 것은 아닙니다.

각 생성의 실제 프롬프트, 입력·출력 정보는 별도 비공개 제작 기록에 보관했습니다. 공개 도구는 ImageGen을 호출하지 않으며 원화 생성 비용이나 계정을 관리하지 않습니다.

## 4. 투명 시트 분리와 화면 배치

시트를 6칸으로 분리하고 원래 알파를 유지했습니다. 작은 분리 영역을 자동 삭제하지 않아 손가락·머리카락 같은 세부가 지워지는 것을 피했습니다.

이번에는 전 원화에 같은 1.7배 배율을 사용했습니다. 얼굴의 가로 기준점과 발 아래 기준으로 이동 위치를 기록하고, 720×1280 화면에 배치했습니다. 얼굴만 따로 늘리거나 원화별 전신 높이를 강제로 같게 만들지 않았습니다. 이 방식도 작화 자체의 비율 차이를 자동으로 해결하지는 않습니다.

## 5. 타임라인과 중간 프레임

원본 프레임 번호를 기준으로 포즈가 등장하는 시간을 설정했습니다. 시작 그림은 원본 46프레임까지 정지 시간을 유지하도록 명시했습니다. 나머지는 기본적으로 다음 키 직전 최대 4개의 원본 프레임 구간에서 연결합니다.

별도 설치된 ComfyUI의 프레임 보간 구현과 기존 RIFE v4.26 체크포인트를 로컬 Python에서 직접 사용했습니다. ComfyUI 웹 화면이나 노드 워크플로 파일로 실행한 것은 아닙니다.

RIFE가 두 벨리무맙 원화 사이의 픽셀 이동을 추정하면, 해당 이동으로 한쪽 전신 원화를 변형합니다. 두 그림을 단순 투명도 겹치기로 섞는 대신 전환의 전반/후반에 사용할 원화를 선택합니다. 이 선택 지점에는 여전히 튐이 생길 수 있습니다.

얼굴 보호 영역에서는 흐름을 한 방향의 이동으로 정리해 눈·얼굴이 늘어나는 현상을 줄였습니다. 이 처리는 회전·표정·해부학을 재생성하는 기능은 아닙니다.

첫 초안은 한 부위의 큰 변형 때문에 화면 전체의 움직임이 약해질 수 있었습니다. 수정본은 변형이 큰 부근만 제한하도록 바꿨습니다. 얼굴·손의 오류를 줄이면서 다른 부위의 움직임까지 일괄 약화시키지 않기 위한 변경입니다.

## 6. 합성과 검증

회색 단색 배경에 합성하고, 원본 1.2–4.2초 음원을 AAC로 인코딩해 넣었습니다. 영상은 H.264, 720×1280, 60fps, 180프레임입니다. 60fps가 180개의 독립 원화 또는 물리적으로 정확한 동작을 의미하지는 않습니다.

전체 디코딩, 프레임 수, 시간 순서, 빈 인물 프레임과 화면 가장자리 잘림을 확인했습니다. 원본/출력의 48kHz 모노 디코드 음원 144,000샘플의 상관계수는 약 0.99884였습니다. 음원은 재인코딩했으므로 비트 동일한 파일은 아닙니다.

시각 검수는 전구간에서 3프레임 간격의 시트와 전환 표본으로 했습니다. 모든 프레임의 작화를 각각 승인한 것은 아닙니다. 얼굴과 의상의 기준은 비교적 유지되지만, 전환의 튐과 가운·머리카락 실루엣 차이는 후속 검토 대상으로 남습니다.

## 공개 소스로 재현할 수 있는 범위

검수한 RGBA 원화와 배치·타임라인 설정을 준비하면 공개 CLI로 분리·배치·렌더·검수 과정을 실행할 수 있습니다. 모델·ComfyUI·FFmpeg는 별도로 공급해야 합니다. 이전 Rin 작업의 여러 버전 폴더는 필요하지 않습니다.

이번 캐릭터 원화, 원본 영상·음원, 캐릭터별 준비 기록은 별도 제작자료에 있습니다. 공개 저장소만 내려받아 벨리무맙 영상 전체가 즉시 재생성되는 구성은 아닙니다. 원화 생성은 같은 프롬프트로 다시 요청해도 비트 단위 재현을 보장하지 않습니다.
